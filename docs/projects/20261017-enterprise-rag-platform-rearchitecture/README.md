# LightRAG 企业级知识库运营平台重构规划 (Enterprise RAG Platform Rearchitecture)

- **时间：** 2026-10-17
- **目标：** 告别玩具 Demo 感，将当前 LightRAG WebUI 全面重构成工业级、高可用、可观测的企业级知识库运营中台（对标 Dify / FastGPT / Linear 工业水准）。
- **影响模块：** `lightrag_webui/src/` (全量组件层、路由层、状态机、API 交互层)、外挂治理路由 `run_lightrag_webui_server.py (/ops)`
- **状态：** 架构规划中（暂不编码，深度对齐方案）

---

## 核心架构承诺（底线）

- **平台端改动：** 0 行代码修改（上层消费平台通过 FastMCP 8 大工具网关消费，契约 100% 稳定）
- **上游侵入度：** 0 行代码侵入（`lightrag/` 官方核心算法库保持绝对纯净，随时无缝拉取上游新特性）
- **工程稳健性：** 前端全量单测保护、构建耗时受控在 2 秒内、保持双守护进程高可用。

## 一、现状审视：为什么现在的前端像个玩具 Demo？

港大官方附带的 WebUI 本质是一个供研究人员快速查看图谱与测试问答的“轻量探针”，缺乏现代企业级知识中台（如 Dify、FastGPT、Linear、Notion）的核心基因：

1. **骨架简陋，缺乏中后台导航体系（App Shell 缺失）**：
   - 顶部只有一个单薄的 Tab 条（`[文档] [知识图谱] [检索]`），缺乏企业级 SaaS 标志性的**左侧多级可折叠中控侧边栏（Sidebar Navigation）**；
   - 工作区切换只是个右上角的生硬下拉框，没有工作区概览卡片、没有跨租户/跨项目层级感。
2. **文档知识管理（Document Hub）单薄如纸**：
   - 扁平单一的表格列表，**没有文件夹/目录树（Folder/Taxonomy）**，文档超过 20 个页面直接混乱；
   - **缺乏沉浸式文档双栏对照器**：用户无法直观对比“左侧原文档预览”与“右侧切片/提取实体/向量分数”的精细化关联；
   - 缺乏批量运维动作（批量重跑抽取、批量切分策略调整、批量删除）。
3. **检索与会话控制台缺乏生产工作台体验**：
   - 会话历史全堆在浏览器临时状态，**缺乏多会话树形归档（Session Drawer / History）**，无法重开历史会话或持久化存储；
   - **缺乏 RAG 调优实验台（Side-by-Side Playground）**：无法在同一问题下横向对比两种检索模式（如 Mix vs Hybrid）的召回结果、Token 消耗与响应质量；
   - 缺乏 Prompt 模板预设与系统人设在线微调。
4. **后端强大的企业级治理能力未被可视化**：
   - 我们底层拥有 **POSIX CAS 零锁原子切换、SHA-256 快照封印、秒级原子回滚、读租约排空** 等核弹级工业能力；
   - 但在前端几乎完全隐形！用户看不见版本发布历史流水线，看不见候选沙箱待发布对比，也无法一键触发秒级回滚。
5. **系统监控与资产看板完全空白**：
   - 整个知识库有多少实体、多少关系、切片总数、Token 消耗历史、查询热词排行，没有任何仪表盘呈现。

## 二、后端能力真实盘点：我们具备了什么？还缺什么？

### 1. 已具备的强悍后端能力（底座极为扎实）
| 后端能力 | 物理支撑模块 | 接口状态 | 赋能前端场景 |
|---|---|---|---|
| **多租户/多项目工作区隔离** | `workspace_manager.py` | `/ops/workspaces` | 企业多部门、多项目自由切换 |
| **CAS 零锁原子版本发布** | `workspace_manager.py` | `/ops/candidates/activate` | 知识库热更新，读写零锁零阻塞 |
| **秒级原子快照封印与回滚** | `snapshot_manager.py` | `/ops/snapshots`, `/ops/snapshots/rollback` | 知识版本管理、误操作秒级恢复 |
| **文档全文与切片反查** | `run_lightrag_webui_server.py` | `/ops/documents/{doc_id}/content` | 双栏沉浸式切片与原文对照 |
| **异步读租约与优雅排空** | `lease_manager.py` | 底层透明接管 | 保证高并发查询与版本切换不冲突 |
| **六大检索模式与流式输出** | `lightrag/` + FastMCP | `/query`, `/query/stream`, MCP 8001 | 支撑各类业务模式与流式打字机 |

### 2. 需要在后端 `/ops` 外挂轻量扩展的支撑接口（0侵入核心库）
为支撑企业级前端，只需在 `run_lightrag_webui_server.py` 的外挂 `ops_router` 中轻量补充：
1. **多会话管理 API** (`/ops/sessions`)：支持会话创建、历史列表拉取、单个会话消息加载与重命名（持久化到工作区内 sqlite 或 json）；
2. **知识库资产统计 API** (`/ops/metrics/overview`)：聚合返回实体数、关系数、切片数、文件总大小与向量存储分布；
3. **文件夹/标签元数据 API** (`/ops/folders`)：为文档打上目录分类标签，实现树形目录展示。

### 1. 资产概览大盘 (Dashboard & Analytics)
- **数据卡片**：总文档数、切片总量（Chunks）、知识实体（Entities）、关系连线（Relationships）、存储占用；
- **健康度雷达**：解析成功率、LLM 缓存命中率、平均检索时延；
- **核心实体与热词词云**：高频核心实体分布与关联度 Top 10。

### 2. 知识资产中枢 (Knowledge Hub 2.0)
- **树形目录与分组**：支持在左侧构建业务文件夹（如“运维规程”、“接口契约”、“需求规范”），文档拖拽归类；
- **沉浸式双栏检视器 (Document Inspector)**：
  - 点击列表任意文档，全屏展开双栏视图；
  - **左栏**：原文高亮渲染（支持 Markdown / 代码 / PDF 原文）；
  - **右栏**：对应的切片列表（Tokens、切片序号、向量相似度、提取出的实体标签与关联关系）；
- **任务流水线实时监控**：
  - 将后台的 Parsing ➔ Extracting ➔ Embedding ➔ Merging 流水线以步骤条方式透明展示，失败文档一键查看详细堆栈并单独重试。

### 3. 智能工作台与 RAG 对比评测台 (Query Console & Playground)
- **双模工作台**：
  - **日常问答模式 (Chat Mode)**：左侧为多会话历史树，中间为黄金行宽对话流，右侧为证据溯源抽屉；
  - **评测对比模式 (Playground Mode)**：专为知识库管理员研发！支持左右双栏分屏，输入同一个 Query，左栏跑 `Hybrid (Top-K=10)`，右栏跑 `Mix (Top-K=20)`，并排对比回答质量、检索切片差异与生成耗时！

### 4. 知识图谱工坊 (Graph Studio 2.0)
- **从“毛线球”到“实体驱动局部探索”**：
  - 支持实体搜索联想输入，回车自动聚焦并展开 1~2 度邻居子图；
  - 实体类型分色过滤（如分为人物、组织、时间、规范、接口等不同色系）；
  - 点击任意实体，右侧面板展示该实体的详细描述与反查的文档切片清单。

### 5. 版本发布总线 (Release & Snapshot Console)
- **将后端核弹级能力彻底可视化**：
  - **版本流水线 (Revision Timeline)**：像 Git 提交历史一样列出 `rev_1`, `rev_2`... 以及对应的快照签名与时间；
  - **候选沙箱待发布预览 (Candidate Staging)**：当后台通过脚本或平台导入新知识时，显示“待发布候选沙箱”，列出变更统计（新增X个实体，更新Y个切片），提供绿色大按钮「一键原子发布」；
  - **一键原子回滚**：发现新版本回答有误，在历史版本卡片上点击「立即回滚」，10毫秒内完成软链切换，全站秒级回退！

## 四、实施里程碑规划 (Phased Roadmap)

严格遵循 KISS 原则，分阶段小步快跑推进：

- **阶段一 (Phase 1) - 全局框架与设计系统升级 (App Shell & Navigation)**：
  - 实现现代化折叠侧边栏、统一设计规范、多租户上下文无缝切换。
- **阶段二 (Phase 2) - 知识资产中心与双栏检视器 (Knowledge Hub)**：
  - 实现目录树、文档沉浸式双栏切片对照、流水线任务透视。
- **阶段三 (Phase 3) - 智能工作台多会话与 Playground 对比评测台**：
  - 实现会话持久化、双模型/双参数并排对比评估。
- **阶段四 (Phase 4) - 版本发布总线可视化 (Release & Snapshot Console)**：
  - 接入后端 CAS 发布、候选沙箱 Diff 预览、秒级回滚面板。
- **阶段五 (Phase 5) - 图谱探索工坊 2.0 与资产看板 (Graph & Dashboard)**：
  - 实体中心化局部展开、统计指标大盘。
