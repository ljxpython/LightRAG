## 任务详情

### Task 1: 对比聚合 API 与指标差分计算引擎
- **改动内容：** 
  - 在 `run_lightrag_webui_server.py` 中新增 `POST /ops/evaluation/runs/compare` 接口；
  - 接收 2~4 个 `targets` 列表（支持组内多模式与跨场次打擂）；
  - 提取 baseline 与 comparison 的五维指标差分、综合分差分、胜负平战况统计；
  - 计算切片 Jaccard 相似度、共有切片与特有切片指纹提取、答案文本适配；
  - 生成老王智能选型建议横幅。
- **状态：** `[x]` 已完成并现场实测通过。
